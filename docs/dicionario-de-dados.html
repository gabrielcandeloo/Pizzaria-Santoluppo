Tabela Cliente

Atributo Descrição Regra de negócio associada
ID_CLIENTE Identificador único do cliente no sistema. Obrigatório (PK). Valor numérico gerado automaticamente.
NM_CLIENTE Nome completo do consumidor. Obrigatório (varchar). Utilizado para identificação no balcão e no delivery.
DS_TELEFONE Número de telefone de contato. Obrigatório (varchar). Utilizado para histórico e validação. Exemplo fictício: (11) 99999-0000.
DS_RUA Nome da rua para envio da encomenda. Obrigatório se o atributo TP_ENTREGA (no Pedido) for "Delivery". Exemplo fictício: Rua das Flores, 123.
DS_BAIRRO Bairro da morada de entrega. Obrigatório se a modalidade do pedido for "Delivery".
CD_CEP Código de Endereçamento Postal. Obrigatório se a modalidade do pedido for "Delivery". Exemplo fictício: 00000-000.

Tabela Pedidos

Atributo Descrição Regra de negócio associada
ID_PEDIDO Identificador único da comanda gerada. Obrigatório (PK). Valor numérico.
DT_PEDIDO Data e hora em que a venda foi aberta. Obrigatório (datetime). Guarda o momento exato da compra.
TP_ENTREGA Classifica a modalidade logística da encomenda. Obrigatório. Valores restritos a: [Delivery, Retirada]. Se "Delivery", aciona a obrigatoriedade de endereço no Cliente.
ID_CLIENTE Referência ao cliente que realizou a compra. Obrigatório (FK). Vínculo mandatório (1,1) para impedir a criação de pedidos anónimos.

Tabela Pizza

Atributo Descrição Regra de negócio associada
ID_PIZZA Identificador exclusivo da pizza no catálogo. Obrigatório (PK). Valor numérico.
DS_SABOR Variação de sabor do produto de fabrico próprio. Obrigatório (varchar). Exemplo: Calabresa, Marguerita.
TP_TAMANHO Dimensão da pizza selecionada. Obrigatório (varchar). Valores possíveis restritos a: [P, M, G].
VL_PRECO Preço de venda comercial estipulado. Obrigatório (numeric). Valor base para a composição do faturamento.

Tabela Pagamentos

Atributo Descrição Regra de negócio associada
ID_PAGAMENTO Identificador do registo financeiro (faturamento). Obrigatório (PK).
VL_TOTAL Montante financeiro total cobrado na operação. Obrigatório (numeric). O processamento exige o compromisso financeiro atrelado à venda.
ID_PEDIDO Vínculo com a comanda de origem. Obrigatório (FK). Relação de 1:1, garantindo o lastro financeiro (não existem pedidos sem prestação de contas).
ID_FORMA_PGTO Referência à modalidade escolhida para o acerto. Obrigatório (FK). Deve remeter a um ID válido no catálogo de formas de pagamento.

Legenda

Termo 1: PK
Significado 1: Primary Key (Chave Primária) - Identificador único da tabela.
Termo 2: FK
Significado 2: Foreign Key (Chave Estrangeira) - Campo que faz referência à chave primária de outra tabela.
Termo 3: varchar
Significado 3: Tipo de dado de caracteres de comprimento variável usado em bancos de dados relacionais para armazenar textos e números..
Termo 4: numeric
Significado 4: Tipo numérico exato usado para armazenar números com precisão e escala fixas.
Termo 5: datetime
Significado 5: Tipo de dado ou módulo usado em programação para representar e manipular informações de data e hora simultaneamente.
